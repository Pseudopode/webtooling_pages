Embedded libraries & licenses
Compression: fflate 0.8.2 and fzstd 0.1.1 by Arjun Barrett (MIT); @bokuweb/zstd-wasm 0.0.27 (package declares MIT), using Zstandard (BSD). Sources: https://github.com/101arrowz/fflate ; https://github.com/101arrowz/fzstd ; https://github.com/bokuweb/zstd-wasm ; https://github.com/facebook/zstd .
The Emscripten zstd loader is embedded with its ES module export replaced by an IIFE return. The 251806-byte WASM payload is unmodified. No third-party code or assets are fetched at runtime.
