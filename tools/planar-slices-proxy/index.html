Display

Drag to orbit, scroll to zoom. Feature and plane-space inspectors explain the selection.

Selection parameters

Coverage

Coverage priorities share the maximum-plane budget. Thin-part detection is heuristic; uncovered detections are reported. Partial sections retain only contours passing the normal-angle filter and cannot be filled.

Export

GLB and JSON preserve source scale and position. Fills preserve holes within each mesh primitive; open or ambiguous contours are left unfilled. Source textures and animation are not included.
