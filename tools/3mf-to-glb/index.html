High memory usage

Conversion, preview and GLB export may use several gigabytes of memory. The browser tab could become slow, freeze or crash. Available memory is not guaranteed by this approval.

Continuing allows this entire model, for this import only. All triangles are retained; nothing is decimated or simplified. Other package-size and GLB format limits still apply.

Preserve the model. Keep the source.

Open a 3MF, inspect its scene and conversion checks, then click Export GLB. The output is a single file containing geometry, material resources, and embedded textures.

What is converted natively?

Triangle meshes, build items, component hierarchy and instances, source placement, physical scale, base materials, vertex colors, PNG/JPEG textures, texture coordinates, and supported metallic/roughness properties. Z-up source coordinates are converted to Y-up meters through a named root transform.

What does “same data” mean?

3MF and GLB have different purposes. Manufacturing settings, unsupported extensions, custom files and original numeric precision have no guaranteed native GLB equivalent. With Embed the exact 3MF enabled, the untouched input is included inside the GLB and can be recovered byte for byte by this page. This does not make those printing features editable in a standard GLB viewer.

Important limits

Vertex colors use glTF’s linear interpolation; 3MF sRGB gradients may look different. Unsupported display effects, layered textures and transparent-border tiling are flagged. No beam-lattice, slice-only, implicit/volumetric geometry conversion or proprietary painted-filament decoding is implemented. Surface normals are generated without changing triangle shapes. GLB vertex coordinates use float32; the archived 3MF retains original numbers. Lighting is a neutral preview, not an original printer/rendering environment.

Compressed input limit: 256 MB. Expanded package: 512 MB, with a 256 MB per-part limit. Unique triangles: 2 million without confirmation. Larger models are allowed after you approve a warning dialog for that import. The triangle threshold is not a hard maximum; browser memory and other package/format limits still apply. Very large files can consume substantially more browser memory than their compressed size. A modern desktop browser with native raw-deflate decompression is required. WebGL2 is preferred; a slower, approximate CPU preview is included when GPU rendering is unavailable. SHA-256 also has a built-in fallback.

Depth precision

Camera clipping planes automatically track the full model bounds, including when framing a selected part. This avoids the depth-precision speckling that affected thin, layered city models in version 1.1. Selection uses a 24-bit depth buffer. These preview changes do not move vertices or affect the GLB. Exactly overlapping source faces can still require source-level repair; this viewer does not hide them by offsetting geometry.

Controls

Drag: orbit. Shift-drag/right-drag: pan. Wheel: zoom. Click: select. Double-click: frame selected part. F: frame all. W: wireframe. G: grid. Escape: clear selection. Visibility, shading, lights and helpers are preview-only.
