# QuickTiny standalone tools

The collection contains every one of the **57 tools in the supplied screenshots**, plus the custom PDF-to-JPG extractor: **58 tools and an index**. Open [dist/index.html](dist/index.html), or open any tool HTML file directly.

Each file includes its required CSS, JavaScript, and selected dependencies. The interface uses warm ivory, sand and terracotta, with English/French switches and small flags. Switching languages preserves entered values and current results. Language follows local navigation and may be remembered locally; user files and text are never uploaded. Keep sibling files together for navigation.

## Practical behavior

- PDF Tools merges files in a reorderable list, extracts/deletes/rotates pages, splits pages into ZIP files, optimizes PDF structure, and creates image PDFs. PDF-to-JPG retrieves original JPEG bytes when they fit the requested limit, otherwise recompresses; whole-page rendering is available separately.
- Product cutouts use edge-color selection and manual erase/restore brushes. This is explicit editing functionality and is not described as a learned AI segmentation model. QR outputs are genuine QR codes, tested with an independent decoder. Image conversion bundles HEIC decoding; output formats are offered only when the browser can actually encode them. CV PDF export uses the browser Print / Save as PDF dialog.
- OCR embeds Tesseract, its WebAssembly core, and English/French/Arabic data. Auto Subtitles embeds multilingual Whisper Tiny, ONNX Runtime and model files. Recognition-enabled pages are larger because they do not need to fetch recognition assets. Recognition is approximate; review every result.
- AI Clip Maker can run bundled Whisper speech recognition to create timed captions and align cuts, alongside measured audio energy/activity and editable ranges. Highlight ranking remains a transparent local heuristic; it does not claim semantic face tracking or a cloud language model. Silence Remover compares actual quiet intervals before retaining edge padding. Caption tools accept scripts and SRT/VTT.
- Video tools render real frames and use the browser’s MediaRecorder. Exports retain sound when a source has decodable audio. MP4 is selected when supported; WebM is the fallback with the correct extension. Rendering runs in real time; keep the tab active. Browser codecs vary. Thirteen video templates have distinct rendering paths. Creator Studio is a working project planner and media inspector that links the focused tools.
- Hardware tools measure actual browser gamepad/mouse events. Some APIs require HTTPS or localhost and browser/hardware support. The mouse frequency result is a browser-event rate, not a guaranteed hardware polling rate.
- JWT verifies signatures with a chosen algorithm and key; decoding alone is not authentication. Regex executes in a worker with a timeout. Cron implements standard five-field semantics with timezone/DST handling.
- Salary, loan, BMI and due-date tools are estimators with their assumptions visible. GOSI profiles use effective dates and registered wage. Prayer times depend on location/method; Ramadan dates are calendar estimates pending local moon-sighting announcements. User-supplied rates are required for Fitr/fidya. Source references and material limitations are in the guides and source directories.

## Development and verification

Use Node 20+ (Node 22+ recommended for WASM engine tests). The build has no dependency installation step: run `node build.mjs` to regenerate all 59 HTML files from source and bundled vendors. The output is reproducible.

For tests, run `npm install`, then `npm test`. This checks the screenshot inventory, standalone scripts/assets, all 58 actual DOM interfaces, French/English input preservation, group algorithms, QR decoding, exact JPEG byte limits, signature verification, DST, real native-raster frames, actual bundled OCR and speech inference. `npm run test:legacy` checks the earlier tools in more detail.

`npm run package` creates `../quicktiny-standalone-tools.zip`. The ZIP contains every standalone page and all third-party license notices. `node tests/delivery.mjs` validates it.

Optional HTTP preview: `npm start`, then open http://localhost:4173 . Serving via HTTPS or localhost makes hardware APIs available where the browser requires a secure context.

Actual browser screenshot and MediaRecorder/hardware verification remain limited by the current macOS sandbox, which denies Chromium process startup. DOM tests use actual generated HTML plus a native canvas adapter; those checks are not a substitute for browser recording or physical hardware tests. All bundled recognition engines were tested on real data without remote models.

Third-party notices are embedded in HTML and included in the ZIP. Versions, licenses and origins are recorded under `vendor/` and `src/extra/*/SOURCES.md`. All application UI/utility code is authored for this project; it is not a copy of the source website’s implementation.
